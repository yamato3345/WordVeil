# Wordveil

## Запуск desktop-застосунку

З кореня проєкту:

```sh
make dev
```

Команда запускає PostgreSQL і Go API у Docker, автоматично застосовує міграції,
чекає готовності API, а потім запускає Tauri на комп’ютері та відкриває вікно
програми. Залежності npm встановлюються автоматично, якщо Tauri CLI відсутній.
Після зміни `package-lock.json` виконайте `npm --prefix client ci`.

На комп’ютері потрібні Make, Docker Engine з Docker Compose, Node.js 24,
Rust/Cargo та [системні залежності Tauri](https://v2.tauri.app/start/prerequisites/).
Запускайте команду зі звичайного термінала графічної сесії.

Tauri використовує локальний Vite як dev-сервер усередині свого вікна.
Окремого контейнера клієнта немає. Vite слухає `127.0.0.1:1430`;
запити `/api` пересилаються до API на `127.0.0.1:8080`.
Обидва порти мають бути вільними перед запуском.

Зміни React-коду підхоплюються автоматично. Після змін Go-коду повторіть
`make backend`, щоб перебудувати сервер.

## Зупинка та діагностика

`Ctrl+C` у терміналі з `make dev` зупиняє desktop-клієнт і його Vite.
Сервер і база продовжують працювати у фоні.

```sh
make logs       # логи API та PostgreSQL
make down       # зупинити Docker-середовище зі збереженням бази
make backend    # запустити тільки API, базу та міграції
```

Перевірка API: http://localhost:8080/main/.

Compose використовує окрему тестову базу й фіксовані локальні паролі.
`.env` не потрібен; `server/.env` не копіюється в образ.
Наявний `server/docker-compose.yaml` залишається окремим середовищем
для розробки Go на хості.

`docker compose down --volumes` видаляє всі дані кореневого тестового середовища.
